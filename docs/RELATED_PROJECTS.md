# Projetos relacionados / Related projects

## PS3

- [ps3recomp](https://github.com/sp00nznet/ps3recomp) — o toolkit de recompilação estática de PS3 sobre o qual este port é construído (runtime, HLE, lifters PPU/SPU). *The toolkit this port is built on.*
- [God of War Ascension Recompiled](https://github.com/MaChInEgUn3/God-of-War-Ascension-Recompiled) — outro port sobre o ps3recomp; modelo da estrutura deste repositório. *Another ps3recomp port; this repository's layout follows it.*
- [Tourline Prologue](https://github.com/mathewdouglas/Tourline-Prologue) — port de *Gran Turismo 5 Prologue* sobre o ps3recomp; a mesma corrida de créditos no `JobGuard` da SPURS foi achada lá. *GT5 Prologue port on ps3recomp.*
- [RPCS3](https://github.com/RPCS3/rpcs3) — emulador de PS3. Usado só como comportamento observado, nunca como fonte de constantes (regra do `CONTRIBUTING.md` do ps3recomp). *Used as observed behaviour only.*

## Outras recompilações estáticas / other static recompilation projects

- [N64Recomp](https://github.com/N64Recomp/N64Recomp) e [N64ModernRuntime](https://github.com/N64Recomp/N64ModernRuntime) — Nintendo 64.
- [XenonRecomp](https://github.com/hedge-dev/XenonRecomp) e [XenosRecomp](https://github.com/hedge-dev/XenosRecomp) — Xbox 360 (CPU e shaders).
- [UnleashedRecomp](https://github.com/hedge-dev/UnleashedRecomp) — port de *Sonic Unleashed* (Xbox 360).
